# NEAT — No Exceeding Awful Tabs

**A lightweight Chrome extension that stops tab-hoarding by forcing links to open in the current tab.**

[![Manifest V3](https://img.shields.io/badge/Manifest-V3-blue.svg)](https://developer.chrome.com/docs/extensions/mv3/intro/)
[![Chrome Supported](https://img.shields.io/badge/Google%20Chrome-Supported-green.svg)](https://www.google.com/chrome/)

## The Problem

Im tired of ending up with 3+ open tabs after a simple tab serfing

## The Solution

**NEAT**  intercepts link clicks in real-time, neutralizes intrusive `_blank` targets, and overrides JavaScript popups without breaking native browser behaviors.

## Controls
| Action | Result |
| :--- | :--- |
| **Left Click** | Neatly opens  link in the **current tab** |
| **Wheel Click** | Neatly opens link in a **new tab**|

## Installation
Works on **Google Chrome** maybe any other Chromium-based browser.

1. Download release or [click here to download release]([https://github.com/your-username/no-exceeding-awful-tabs/archive/refs/heads/main.zip](https://github.com/medovichka/NoExceedingAwfulTabs/archive/refs/tags/release.zip)).
2. Unpack the downloaded archive to any permanent folder on your PC.
3. Go to chrome://extensions/ and select load unpacked extension, select folder "NEAT" from extracted archive.
4. Do not delete or move this folder after installation. If you delete it, the extension will stop working.
